## [NVIDIA Launches Ising, First Open-Source Quantum AI Model Family](http://nvidianews.nvidia.com/news/nvidia-launches-ising-the-worlds-first-open-ai-models-to-accelerate-the-path-to-useful-quantum-computers) ⭐️ 9.0/10

NVIDIA has released Ising, the world's first open-source family of AI models specifically designed to accelerate quantum computing development. The suite includes Ising Calibration, a 35-billion-parameter vision-language model that reduces quantum processor calibration time from days to hours, and Ising Decoding, a 3D convolutional neural network for error correction. Ising Decoding demonstrates a 2.5x speed improvement and 3x higher accuracy compared to the existing open-source standard, pyMatching. This release addresses two critical bottlenecks in quantum computing: the slow calibration of qubits and the complex decoding of error corrections, which are essential for building useful quantum processors. By open-sourcing these tools, NVIDIA aims to establish AI as the de facto 'operating system' or control plane for future quantum machines, significantly lowering the barrier for research institutions and enterprises. The substantial performance gains over current standards like pyMatching suggest a potential paradigm shift in how quantum systems are managed and optimized. Ultimately, this integration of AI and quantum hardware could accelerate the timeline for achieving practical, fault-tolerant quantum applications. Ising Calibration is trained on data spanning multiple qubit types, including superconducting qubits, quantum dots, ions, and neutral atoms, ensuring broad compatibility across different hardware architectures. The models are available for local deployment via GitHub, Hugging Face, and build.nvidia.com, a feature designed to protect proprietary data for enterprise users. Leading institutions such as Fermi National Accelerator Laboratory, Harvard University, IQM, and the UK's National Physical Laboratory have already adopted the models for their research.

The report details how agents struggle with end-to-end reasoning tasks that require retrieving information from multiple sources and executing sequential API calls. This analysis is critical because as AI agents move from simple chatbots to autonomous workers, understanding their specific breaking points in real-world enterprise scenarios becomes essential for safe deployment. Unlike previous single-turn evaluations, VAKRA highlights systemic failures in coordination and logic that occur only during multi-step workflows involving external tools. These insights allow developers to move beyond basic accuracy metrics and address fundamental architectural weaknesses in agent orchestration. Ultimately, this work sets a new standard for rigorously testing the reliability of agents before they are entrusted with critical business operations. The VAKRA benchmark is tool-grounded and executable, meaning agents must actually perform API calls and retrieve knowledge rather than just simulating the process in text. The analysis categorizes failures into specific areas such as incorrect tool selection, hallucinated parameters, and inability to chain multiple reasoning steps effectively. It reveals that many state-of-the-art models fail significantly when required to synthesize information from disparate sources to solve a single complex query. The study provides concrete examples of these failure modes to help engineers debug and improve their agent frameworks.

## [Cloudflare Launches Mesh for Secure AI Agent and Device Networking](https://blog.cloudflare.com/mesh/) ⭐️ 8.0/10

Cloudflare has officially launched Mesh, a new private networking service built on Cloudflare One that enables bidirectional connectivity between users, remote devices, and AI agents. This service allows up to 50 nodes and 50 users to connect for free via a single lightweight connector, integrating directly with Workers VPC to let AI agents access internal APIs and databases securely. Unlike traditional tunneling solutions that offer only unidirectional proxy access, Mesh facilitates direct peer-to-peer communication using private IP addresses within the network. This development is critical for the AI industry as it solves the longstanding challenge of securely deploying AI agents that need to access private internal resources without exposing them to the public internet. By unifying humans, agents, and multicloud infrastructure into a single secure fabric, Mesh provides the necessary networking backbone for complex AI workflows that require real-time data from internal systems. It significantly lowers the barrier for developers to build cross-cloud applications where AI agents can act autonomously on behalf of users while maintaining strict security boundaries. Compared to existing SD-WAN or zero-trust solutions, Mesh's native integration with serverless functions like Cloudflare Workers offers a more streamlined path for modern application architectures. The service currently supports a free tier allowing 50 nodes and 50 users, utilizing a single binary connector to establish multi-to-multi network connections. While it currently enables basic private IP connectivity, Cloudflare plans to introduce hostname routing, Mesh DNS, and identity-aware routing later this year to enable finer-grained access control based on specific agent or user identities. The integration with Workers VPC means that code running on Cloudflare's edge can now natively reach into private networks without complex gateway configurations. However, advanced features like identity-based policies are not yet available and will be rolled out in future updates.
